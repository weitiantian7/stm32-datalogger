# 验收记录模板与发布前核对

本文件是待填写模板，不是测试通过报告。源码整理未运行 Keil 编译，也未连接目标硬件。

## 本次整理检查

- 原工程所引用的源文件和 IncludePath 目录已检查存在。
- 保留的原文件逐字节复制，未修改业务源码。
- 移除 Keil 编译产物、个人界面状态以及未引用的 CMSIS DSP/NN 内容。
- 原包未提供可核验的实测报告，不能从计划书推导性能结果。
- 已按新版源码确认：0x41 通过 `Storage_ReadHistory()` 将历史读取交给存储任务，回复包含请求编号，调用等待超时参数为 1500 ms。

## 发布前优先核对

1. 在另一目录打开工程完整重编译，记录 Keil、编译器与设备包版本、代码/RAM 用量和结果。
2. 对已统一到存储任务的 0x41 历史读取进行日志写入交错、读取超时及迟到回复复测，记录实际结果。
3. 统一 Modbus 存储故障状态位：常量定义为 bit2，但当前更新路径设置 bit3。
4. 上传实物照片、接线图、实际测试记录和演示链接；检查 README 与实物配置相符。
