# 硬件与接线

下表由当前源码外设初始化与 GPIO 操作整理，实际接线需与开发板和模块引脚标识核对。

| 模块 | STM32 引脚 | 说明 |
| --- | --- | --- |
| SHT30、OLED | PB6 / PB7 | I²C1 SCL / SDA，配置 400 kHz；地址分别为 0x44、0x3C |
| W25Q32 | PA5 / PA6 / PA7 | SPI1 SCK / MISO / MOSI |
| W25Q32 片选 | PA4 | CS，空闲为高 |
| RS485 | PA9 / PA10 | USART1 TX → DI，RX ← RO |
| RS485 方向 | PA11 | 接模块的 DE 和 /RE 控制端，高发低收；按所用模块核对 |
| 模拟量 1 / 2 | PB0 / PB1 | ADC1 通道 8 / 9，输入范围 0～VDDA |
| 蜂鸣器控制 | PB11 | 当前代码低电平报警，需匹配实际模块 |
| LED | PC13 | 工程配置的开漏输出 |
| 下载调试 | PA13 / PA14 | SWDIO / SWCLK |

外设使用与主控匹配的 3.3 V 电平并共地。模拟输入不可直接接高于 VDDA 的电压。Flash 驱动范围为 4 MiB，启动检查 JEDEC ID 为 EF 40 16，替换型号时应一并修改容量、分区和 ID 检查。

当前代码使用 STM32F103C8 目标、W25Q32 和 USART1。不要套用原计划书中 STM32F407、W25Q64、USART3 的接线表。

建议补充实际板卡型号、模块照片、整机接线照片与供电方式后再录制演示。
